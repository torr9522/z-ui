# 022 - x-ui.sh 面板账号与端口管理菜单

## 背景

`x-ui.sh` 原主菜单直接提供随机重置账号密码和随机重置面板端口。运维场景需要在交互菜单中区分“自定义”和“随机”两类操作，同时保持原命令模式兼容。

## 命令变化

保留兼容命令：

- `x-ui reset-user`：继续随机重置账号密码。
- `x-ui reset-port`：继续随机重置面板端口，随机范围为 `10000-59999`。

新增命令：

- `x-ui set-user <用户名> <密码>`：自定义重置账号密码，参数不能为空。
- `x-ui set-port <端口>`：自定义重置面板端口，端口必须为 `1-65535` 的数字。

## 菜单变化

主菜单面板相关项调整为：

- `3. 面板账号密码管理`
- `4. 面板端口管理`

账号密码管理二级菜单：

- `1. 自定义重置账号密码`
- `2. 随机重置账号密码`
- `0. 返回主菜单`

端口管理二级菜单：

- `1. 重置自定义端口`
- `2. 重置随机端口（范围10000-59999）`
- `0. 返回主菜单`

## 行为细节

- 自定义账号密码要求用户名和密码均不能为空。
- 随机账号密码继续使用现有随机生成逻辑，并显式避免 `admin/admin`。
- 自定义端口校验空值、非数字、`0`、大于 `65535` 的输入。
- 随机端口范围固定为 `10000-59999`。
- 设置账号密码或端口后重启 `x-ui` 服务，并显示新账号密码或新面板地址。
- 二级菜单空输入和错误输入不退出脚本。
- `0` 返回主菜单。
- Ctrl+C 仍按主菜单 trap 正常退出。
